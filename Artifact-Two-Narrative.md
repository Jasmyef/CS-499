This artifact is a Java program that manages contacts: add, update, delete, and look up someone. This specific artifact was built by me in my CS 320 class, and it came with a prewritten test. I decided to go with this particular one as looking up someone used to mean checking every single contact until the match was found. This would make the process significantly slower as more contacts were added. I fixed this by storing each contact under its own unique ID. I also noticed four update methods were doing the same things, so I combined those into one shared logic; this lookup feature fix shows the algorithms and data structures part. For this, I was going for Outcome 3, which is solving problems correctly, as well as Outcome 4, which uses the right tools and techniques. For this, at the moment, I can test this all the way through, which helped me greatly as my original test passed even after the changes. I even added a database on top, so contacts don’t disappear when the program closes; this was a bit of a stretch for me as I wanted to be sure that any changes I made did not mess with how things operate as a whole. I learned that you could fix the intent of something without changing its meaning.
